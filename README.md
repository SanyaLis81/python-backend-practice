# Python Backend Practice

Учебный проект для изучения Python и подготовки к позиции Junior Python Backend Developer.

## Что есть в проекте

- `bank.py` — функции для работы с банковскими операциями.
- `test_bank.py` — автоматические тесты для проверки функций.
- `main.py` — основной файл проекта.

## Установка и запуск

1. Установи Python.
2. Создай и активируй виртуальное окружение.
3. Установи pytest:

   ```bash
   pip install pytest
   ```

## Запуск тестов

Из корневой папки проекта выполни:

```bash
pytest
```
